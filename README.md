# Agglomerative Hierarchical Clustering Analysis

A data analysis project that implements **Agglomerative Hierarchical Clustering (AHC)** using Python and Jupyter Notebook. The project uses an Excel dataset to perform clustering analysis and explore patterns within the data.

This project was developed as part of an academic data analysis exercise to understand the implementation and interpretation of hierarchical clustering techniques.

---

## 📌 Project Overview

**Agglomerative Hierarchical Clustering (AHC)** is an unsupervised machine learning technique that groups data points based on their similarity or distance.

In this project, the clustering process is performed using a Jupyter Notebook, starting from dataset preparation and exploration to the implementation and interpretation of the clustering results.

### Main Objectives

- Explore and understand the provided dataset
- Prepare data for clustering analysis
- Implement Agglomerative Hierarchical Clustering
- Analyze the resulting clusters
- Visualize and interpret clustering results

## 📊 Methodology

The project applies **Agglomerative Hierarchical Clustering**, a bottom-up hierarchical clustering approach.

Initially, each data point is treated as an individual cluster. The algorithm then progressively merges the most similar clusters until the desired clustering structure is obtained.

The analysis can be used to identify groups of observations that share similar characteristics based on the selected dataset attributes.
